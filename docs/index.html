How it works

An echo state network (ESN) is a recurrent neural network whose internal weights are random and never trained. Input disturbs it, the disturbance echoes around the network and slowly dies out. Here those echoes are the music.

The network

Between 50 and 800 neurons (200 by default, set with Reservoir size), each connected to about 10% of the others with random weights, scaled so the spectral radius is about 1 before ρ is applied. Every 10 ms (100 Hz) each neuron updates:

x ← (1 − a)·x + a·tanh(ρ·W·x + Win·u + noise)

x is the activation of every neuron, between −1 and 1. u is the input from the ten keys. a is the leak rate and ρ the spectral radius, both on the sliders.

The keys

Q to P are ten input channels. Each one is wired to every neuron through its own random weight, so each key nudges the network in a different direction. Holding a key ramps its input up quickly; letting go fades it out slowly. The blue bar inside a key shows its current input level.

The page only hears your keyboard after you have clicked on it once.

The water view

  • Dots are neurons: blue when positive, red when negative, bigger and brighter when stronger.
  • Ripples spread from a neuron whenever its activation changes. A steadily oscillating neuron sends out a regular train of waves.
  • Thin lines light up along the strongest connections while signal is flowing through them.
  • Outlined rings are hotwired loops: solid for oscillators, dashed for latches.
  • D, L, B mark the neurons currently playing drums, lead and bass.

How neurons become sound

A sequencer reads the network on a sixteenth-note grid at the current tempo.

Drums
Three neurons, one each for kick, snare and hi-hat. A drum hits when its neuron is above the drum threshold; louder when it is further above.
Lead
Every eighth note while the network is active. One neuron picks the pitch on the chosen scale, a second one opens the filter. Busier networks get more reverb.
Bass
Every beat, a filtered saw whose pitch follows one neuron, when that neuron is far enough from zero.

The controls

Spectral radius ρ
How strongly the network feeds back into itself. Below 1 echoes fade, around 1 they ring for a long time, above 1 the network keeps itself going chaotically.
Leak rate
How fast neurons respond. Low values give slow, smooth swells; high values give fast, jittery changes.
Drum threshold
Lower it for busier drums, raise it for sparser ones.
Tempo
Speed of the sequencer that reads the network. It does not change the network itself.
Scale, Voices
Which notes the lead and bass may use, and which parts play.

Hotwiring

Hotwire a ring picks random neurons and connects them in a loop with strong weights. The three voices then follow the ring's neurons.

Oscillator
One connection in the ring is inhibitory, so the loop chases its own tail forever, like an LFO. Longer rings cycle more slowly: 3 nodes about 7 Hz, 9 nodes about 2 Hz.
Latch
All connections excite each other, so one push switches the ring on and it stays on.
Kick network
Pushes every neuron randomly, which restarts rings that have settled.
Unwire all
Removes every ring. The network goes back to fading echoes.

Things to try

  1. Tap one key, then hold another, and listen to how differently each echo decays.
  2. Push ρ to 1.05 and play a few keys. The network will start improvising on its own.
  3. Hotwire a 9-node oscillator, then a 3-node one, and hear two rhythms interlock.
  4. Hotwire a latch, then drop the leak rate to 0.1 for slow, held drones.
  5. Press Play demo to hear echoes first, then two oscillator rings taking over.

The Python version

The same network runs in Python with the Sardine live-coding library and SuperCollider, so you can change the music by editing code while it plays.

python -m pip install sardine-system numpy pynput
sardine
>>> exec(open("esn_live.py").read())
>>> hotwire(1, length=9)
>>> esn.rho = 1.05

Press F8 in the terminal to arm the Q to P keys. esn_offline.py renders a WAV with numpy alone.
